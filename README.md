# KCsillapa74 ระบบรายงานภาพ งานศิลปหัตถกรรมนักเรียน ครั้งที่ 74 โรงเรียนกุดชุมวิทยาคม

หน้าเว็บ: https://rachaproject.github.io/KCsillapa74/

- **📷 ส่งรูป**: ครูเลือกรายการแข่งขันแล้วส่งรูปรวมนักเรียน (เน็ตหลุดรูปไม่หาย เก็บในเครื่องแล้วส่งให้เอง)
- **🏅 สรุปผล**: ภาพสรุปผล 16:9, ตัวเลขรวม, แยกตามกลุ่มสาระ, ผลรายการ (แอดมินกรอกผลและดาวน์โหลดภาพโพสต์/ไวนิล)
- **📋 การส่งรูป**: ส่งแล้ว/ยังไม่ส่ง แยกตามวัน และผลตรวจ AI (แอดมินคัดลอกรายการที่ยังไม่ส่งไปวางใน LINE)

โครงสร้าง
- `index.html`, `css/`, `js/`: หน้าเว็บ (GitHub Pages)
- `js/render.js`: วาดภาพแสดงความยินดี (1080 px โพสต์ / 2400 px ไวนิล ≈100 dpi ที่ 60 ซม.) และภาพสรุปผล (1920 / 4000 px)
- `apps-script/`: หลังบ้าน Google Apps Script และวิธีติดตั้ง

repo นี้ไม่มีข้อมูลนักเรียน รูปถ่าย หรือรหัสผ่าน ทุกอย่างเก็บใน Google Sheets / Drive ของโรงเรียน
