# ติดตั้งหลังบ้าน (Apps Script) ทำครั้งเดียว ประมาณ 10 นาที

## 1. สร้างชีตและวางโค้ด
1. สร้าง Google Sheets ใหม่ ตั้งชื่อเช่น `ศิลปหัตถกรรม 74 กุดชุม`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจาก `apps-script/Code.gs`
4. ใส่ ID ชีตรายการแข่งขันของโรงเรียนที่ `SOURCE_SHEET_ID` ท้ายไฟล์ (ระบบจะอ่านรายการ/นักเรียน/ครูจากชีตนั้นตอน setup)
5. กดบันทึก

## 2. ตั้งค่า
1. กลับไปที่ชีตแล้วรีเฟรช จะมีเมนู **🏅 ศิลปหัตถกรรม 74**
2. **1) ตั้งค่าครั้งแรก** แล้วกดอนุญาตสิทธิ์ ระบบจะสร้างชีต "รายการแข่งขัน" (101 รายการ), ชีต "รูปรายงาน", โฟลเดอร์รูปใน Drive และตัวตั้งเวลาให้ AI ตรวจรูปทุก 5 นาที
3. **2) ตั้งรหัสผ่านแอดมิน** (อย่างน้อย 6 ตัว)
4. **3) ใส่ Gemini API key** (สร้างที่ Google AI Studio) ไม่ใส่ก็ได้ ระบบยังรับรูปได้ปกติ แค่ไม่มี AI ตรวจ

## 3. วางภาพคณะผู้บริหาร
อัปโหลดไฟล์ `executives.png` (ได้รับแยกต่างหาก) ไว้ในโฟลเดอร์ Drive `KCsillapa74 รูปรายงาน` ชื่อไฟล์ต้องตรงตามนี้ ภาพสรุปผลจะดึงไปใช้เอง

## 4. Deploy เป็น Web app
1. ใน Apps Script กด **Deploy → New deployment → ⚙ → Web app**
2. **Execute as: Me** และ **Who has access: Anyone** (ต้องเป็น Anyone ไม่ใช่ Anyone with Google account)
3. กด Deploy แล้วคัดลอกลิงก์ที่ลงท้ายด้วย `/exec` ส่งให้ Claude ใส่ใน `js/config.js`

แก้โค้ดหลังบ้านครั้งต่อไป: **Deploy → Manage deployments → ✏ → Version: New version** ลิงก์เดิมยังใช้ได้

## ข้อมูลในชีต
- **รายการแข่งขัน**: แก้ชื่อรายการ นักเรียน (บรรทัดละคน) ครู ได้ที่นี่ ผลการแข่งขันกรอกในหน้าเว็บ (แอดมิน) หรือในชีตก็ได้
- **รูปรายงาน**: ทุกรูปที่ส่งมา สถานะ AI และการตรวจของแอดมิน (ห้ามลบคอลัมน์)
- รูปอยู่ใน Drive โฟลเดอร์ `KCsillapa74 รูปรายงาน` แยกตามรายการ มีทั้ง `_web.jpg` และ `_original.jpg` (ความละเอียดเต็มสำหรับไวนิล)

## AI ตรวจรูป (โควตาหมดก็ไม่กระทบ)
- รูปถูกบันทึกก่อนเสมอ แล้วเข้าคิว "รอตรวจ"
- ตรวจทุก 5 นาที ครั้งละไม่เกิน 6 รูป ถ้าโควตาหมด หยุดรอบนั้นแล้วตรวจต่อเองเมื่อโควตากลับมา
- ระบบหาโมเดล Gemini ที่ใช้ได้เอง ถ้าต้องการกำหนดเอง: Project Settings → Script properties → เพิ่ม `GEMINI_MODELS`
- แอดมินกด "ผ่าน" / "ให้ส่งใหม่" เองได้เสมอ

## ดึงผลจากเว็บเขต
- ลิงก์หน้าประกาศผลอยู่ที่ `CFG.RESULTS_URL` (หน้า "สรุปเหรียญรางวัล" ของโรงเรียน)
- หน้าเว็บ (แอดมิน) → สรุปผล → **ดึงผลจากเว็บเขต** ระบบจะขึ้นตารางให้ตรวจก่อนบันทึก
- ถ้าดึงไม่ได้ ให้คัดลอกตารางจากหน้าเว็บเขตมาวางในช่อง "คัดลอกตารางมาวางเอง"
- ดึงอัตโนมัติ: เมนู 🏅 → **เปิดดึงผลอัตโนมัติ (ทุก 30 นาที)** ระบบเติมเฉพาะรายการที่ยังไม่มีผล ไม่ทับผลที่แอดมินกรอกเอง ปิดได้จากเมนูเดียวกัน
